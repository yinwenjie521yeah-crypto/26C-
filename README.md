##项目简介
本项目是一个基于 **Qt Widgets + C++** 开发的塔防小游戏。玩家需要在地图上建造不同类型的防御塔，阻止敌人沿道路到达终点。
游戏包含：
- 进入界面
- 游戏说明界面
- 主游戏界面
- 多路径敌人移动
- 多波次出怪
- 三种防御塔
- 防御塔升级与出售
- 多种敌人类型
- Boss 和最终波次
- 胜利 / 失败界面
- 背景音乐与音效

##直接运行版本
可以直接下载 Release 中的：
`final_release_windows.zip`试玩，不需要配置环境，但需要下载完整压缩包
解压后双击 `final.exe` 运行。

## 运行环境要求
若下载本文件，请使用以下环境打开和运行本项目：
### 必需环境（注意路径必须为英文）
- Qt 6.x
- Qt Creator
- CMake
- MinGW 64-bit Kit
- Qt Widgets 模块
- Qt Multimedia 模块
### 推荐环境
本项目开发和测试环境为：
```text
Qt 6.10.2
Qt Creator
Desktop Qt 6.10.2 MinGW 64-bit
CMake
Windows 11
```
