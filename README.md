# 顶流争夺保卫战

本次大作业的题目是 **“顶流争夺保卫战”**。

---

## 项目简介

本项目是一个基于 **Qt Widgets + C++** 开发的塔防小游戏。玩家需要在地图上建造不同类型的防御塔，阻止敌人沿道路到达终点。

游戏包含：

- 进入界面
- 游戏说明界面
- 主游戏界面
- 多路径敌人移动
- 多波次出怪
- 三种防御塔
- 防御塔升级与出售
- 多种敌人类型
- Boss 和最终波次
- 胜利 / 失败界面
- 背景音乐与音效

---

## 直接运行版本

可以直接下载 Release 中的可运行压缩包：

```text
final_release_windows.zip
```

下载后请解压完整压缩包，然后双击其中的：

```text
final.exe
```

即可运行游戏。

注意：不要只单独下载 `final.exe`，必须下载完整压缩包，因为压缩包中包含 Qt 程序运行所需的 `.dll` 文件和插件文件夹。

---

## 运行环境要求

若下载源码并使用 Qt Creator 打开运行，请使用以下环境。

### 必需环境

注意：项目路径建议使用英文路径，避免中文路径导致 CMake 或资源加载异常。

- Qt 6.x
- Qt Creator
- CMake
- MinGW 64-bit Kit
- Qt Widgets 模块
- Qt Multimedia 模块

### 推荐环境

本项目开发和测试环境为：

```text
Qt 6.10.2
Qt Creator
Desktop Qt 6.10.2 MinGW 64-bit
CMake
Windows 11
```
